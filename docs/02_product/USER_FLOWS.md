# User flows

High-level flows for MVP; detail in `PRD_MVP.md` and `UI_HANDOFF_SPEC.md`.

## F1 — Land as guest

Home → skim value → start **onboarding** OR browse **guide** / **search** → optional **account** prompt at value moments only.

## F2 — Complete onboarding

Steps capture situation → **dashboard** populated with **next best actions** and **checklist** subset.

## F3 — Execute a guide task

Search or nav → **guide page** → read + sources → mark checklist / return to dashboard.

## F4 — Account later

Guest attempts save / sync / service request → **sign up** → migrate temp state (engineering detail in `STATE_MANAGEMENT_PLAN.md`).

## F5 — Stay updated

**Updates/alerts** list → open item → land on linked **guide** or **hub**.

## F6 — Sensitive paths (residency, money)

Extra emphasis on **sources** and disclaimers; no skip of provenance UI.
