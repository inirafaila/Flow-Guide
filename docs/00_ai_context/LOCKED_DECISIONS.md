# Locked decisions

These are **non-negotiable** for MVP unless explicitly reopened by humans and recorded in `DECISION_LOG.md`.

| # | Decision |
|---|----------|
| 1 | **Guest-first, account-later** — no forced signup at entry; account when saving path, dashboard persistence, requests, or notifications need it. |
| 2 | **Newcomer-first** — copy, IA, and UI optimize for the arriving user, not admin or partner workflows. |
| 3 | **Home is hybrid** — not purely conversational or purely article index; clear entry to path and actions. |
| 4 | **Mobile-first** — layout and performance target phones first. |
| 5 | **Dashboard is core** — personalized next steps and checklist live here, not optional chrome. |
| 6 | **Source-aware content is required** — legal/financial/admin guidance must carry attributable sources and verification discipline. |
| 7 | **Slugs are English-first** — URL segments and canonical slugs in English; localized display titles separate. |
| 8 | **Payments and transport are separate sections** — do not merge into one vague “daily life” bucket in IA. |
| 9 | **Map is not top-level in MVP** — no full map platform; **places-lite** only as supporting context. |

## Reopening rule

Changes require **explicit human instruction** and an entry in `DECISION_LOG.md`. AI must not silently override this file.
